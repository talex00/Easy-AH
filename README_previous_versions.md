# EasyAH — WoW 1.12.1 / fix1

Исправленная сборка предоставленного пользователем аддона. Целевой клиент: оригинальный WoW 1.12.1, Interface 11200, Lua 5.0. Это НЕ аддон для современного WoW Classic / Retail.

## Установка

1. Полностью выйдите из игры.
2. Скопируйте в безопасное место старую папку Interface/AddOns/EasyAH и файл WTF/Account/<ACCOUNT>/SavedVariables/EasyAH.lua (также .bak, если есть).
3. Замените старую папку EasyAH папкой из этого архива. Итоговый путь: Interface/AddOns/EasyAH/EasyAH.toc. Не переименовывайте папку.
4. На первый запуск отключите старый aux и другие заменители аукциона. ShaguTweaks необязателен.
5. Начните с дешёвого предмета и одной пачки, затем проверьте Stop и закрытие окна. История и настройки сохраняются; удалять SavedVariables не нужно.

## Важно перед первым использованием

- Проверены загрузка с заглушками и 29 регрессионных сценариев. Использован Lua 5.3 с тестовой адаптацией старых конструкций. Клиент WoW 1.12.1, нативный Lua 5.0 и игровой UI НЕ запускались. Это инженерно проверенная, но не подтверждённая игровым тестом сборка.
- Нельзя отменить уже отправленную покупку/ставку/размещение. Stop запрещает новые шаги, но не откатывает действие на сервере.
- При неподтверждённом действии автоматизация отключается. Проверьте реальное состояние лота/сумок/золота, подождите 15 секунд и заново откройте аукцион. Аддон не повторяет денежное действие по таймауту.
- Используйте автоматизацию только там, где её разрешают правила вашего сервера.

## Команды

- /eah — настройки.
- /eah stop — остановить сканы, Post All, размещение и отключить автопокупку/автоставки.
- /eah plan — окно с подробностями последнего плана Post All, включая причины пропуска.
- /eah log — окно с журналом последних операций (хранится до 100 записей на персонажа).
- /eah vendor — включить/выключить цену торговца в подсказке.
- /eah auto — текущие ограничения автоматизации и расход бюджета.
- /eah auto on — разрешить Auto Buy / Auto Bid для текущего посещения аукциона.
- /eah auto off — отключить автоматические покупки и ставки.

Auto Buy / Auto Bid в избранных фильтрах по-прежнему нужно включать отдельно. Обычный поиск сам по себе не покупает, пока автоматизация явно не разрешена командой.

### Консервативные лимиты по умолчанию

- Бюджет: 1 золотая монета на сеанс входа / reload.
- Максимальная стоимость одного лота: 10 серебра.
- Минимальный неприкосновенный остаток: 1 золотая монета.
- Максимум: 20 единиц одного item_key (для зарядовых предметов считаются заряды).

Изменение лимитов, например:

```
/eah auto budget 5g
/eah auto lot 50s
/eah auto reserve 1g
/eah auto quantity 40
/eah auto on
```

Каждая команда настройки выключает разрешение до повторного /eah auto on. Бюджет и количество учитывают отправленные попытки консервативно, включая неоднозначные результаты; повторные ставки учитываются полной суммой. Закрытие и открытие аукциона не обнуляет расход. Reload/повторный вход обнуляет счётчики, но не включает автоматизацию.

## Post и Post All

- Post All сначала сканирует товары, строит план и показывает подтверждение. До подтверждения ничего не выставляется.
- /eah plan показывает цену за лот, число лотов, источник цены и причины пропуска.
- План фиксирует цены; подтверждение действует 60 секунд. Зафиксированная цена живёт не более 5 минут: слишком длинная очередь останавливается и требует нового плана.
- Проверяются и стартовая ставка, и выкуп: продажа по минимальному bid тоже не должна нарушать ограничение доходности над ценой торговца.
- В одиночном Post низкую доходность можно явно подтвердить. Post All такие позиции пропускает.
- Stop находится во вкладке Post; /eah stop доступна всегда. Закрытие аукциона или вкладки Post отменяет пакетную очередь.

### Размер стака для Post All

По умолчанию Post All выставляет всё максимальными стаками. В параметрах предмета (вкладка Post) есть поле «Post All stack (0=max)»:

- **0** (по умолчанию) — максимальные стаки (ткань по 20, трава по 20 и т.д.)
- **1** — по одному предмету (дорогая трава, реагенты для точечной продажи)
- **N** — стаки по N предметов (например, 5 для частичной продажи)

Настройка сохраняется для каждого предмета отдельно. Если не менять — поведение как раньше: максимальные стаки.
- Число лотов, цена и депозит перепроверяются перед каждым StartAuction. Фактический депозит берётся из CalculateAuctionDeposit старого клиента; сумма депозита в предпросмотре приблизительная.
- Для автоцены требуется завершённый свежий скан с загруженными владельцами. Если владельцы не приходят, операция заканчивается отказом, а не угадывает цену.

## Цены и история

- Единый расчёт для предпросмотра и размещения.
- Fixed undercut задаётся в меди за ЛОТ, Percent — процент от цены лота, Match — без снижения.
- Market percentile сохраняется после завершения скана и не заменяется минимумом.
- Число конкурентов — число реальных аукционов, а не сгруппированных строк. Число уникальных продавцов учитывается в снимке отдельно; порог настройки относится к лотам.
- Пустой успешный скан очищает текущую рыночную цену. Прерванный скан не заменяет завершённый снимок.
- Срок свежести текущего рынка — 5 минут. Исторические значения сохраняются отдельно.
- Нейтральный рынок отделён от фракционного; вне аукциона подсказки возвращаются к фракционной истории. Старую смешанную историю задним числом автоматически разделить невозможно.
- Net if sold не вычитает возвращаемый депозит. Возможная потеря депозита при непродаже — отдельный риск.
