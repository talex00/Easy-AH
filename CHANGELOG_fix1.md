# fix1 — 2026-09-05

## Исправления безопасности
- Единый исполнитель денежных операций с подтверждением, таймаутом, отменой и защитой от поздних сообщений.
- Таймаут больше не означает успех. Отказ по деньгам/блокировке всегда возвращает результат.
- Отдельные состояния пакета Post All; старые callback не продолжают отменённый запуск.
- Ограниченные ожидания запросов, владельцев и сборки стаков.
- Post All: предварительный план, подтверждение и замороженные цены; защита от повторного запуска.
- Общая проверка параметров, ставок, выкупа, доходности над торговцем и наличия денег для депозита.
- Сеансовое разрешение Auto Buy/Bid, бюджет, максимум лота, запас золота и ограничение количества.
- Ограниченный журнал денежных операций и причин отказа.

## Рыночные данные и расчёты
- Исправлена пятикратная переоценка предметов с зарядами в vendor-profit и bid-vendor-profit.
- Общий источник vendor sell price; ShaguTweaks без SellValueDB больше не вызывает ошибку.
- Согласованные снимки рынка, атомарная публикация только полного exact-item скана.
- Пустой скан сбрасывает рыночную цену; цена и количество больше не принадлежат разным поколениям.
- Из подсчёта исключаются свои лоты; неизвестный владелец не признаётся конкурентом.
- Подсчёт реальных лотов, сохранение взвешенного процентиля, TTL и отдельный нейтральный рынок.
- Общий undercut для автоматического и ручного режима; единица фиксированного снижения — лот.
- Защита от нулевых/нечисловых коэффициентов и случайного аукциона за 1c без buyout.
- Депозит не вычитается из Net if sold; зарядовые количества нормализованы.

## Другие исправления
- Почтовая подсказка снова вызывает GetItemInfo; Today показывает дневной минимум.
- Similar Items использует название/код слота, распознаваемое парсером.
- Явная arity логических операторов фильтров проверяется.
- Кнопки и горячая клавиша проходят общий безопасный путь; ошибочный ввод не превращается молча в автоцену.
- Десятичные настройки не используют целочисленный GetNumber для коэффициентов.
- Очистка item cache запускает перестройку; ограничено количество обрабатываемых ID за шаг.
- Для сохранённых дат своих персонажей используется time(), а не uptime GetTime().
- Новый планировщик не удерживает временные pooled-таблицы аргументов между кадрами; линейная очистка слушателей.
- Проверка и нормализация длительности, числовых настроек и коэффициентов, schema_version=2.
- Сохранены старые API/события и формат папки EasyAH; исключена папка .git из поставки.
