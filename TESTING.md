# Проверка fix3

- 47 рабочих Lua-модулей: синтаксическая проверка Lua 5.3.
- Загрузка TOC, VARIABLES_LOADED и PLAYER_LOGIN с заглушками WoW.
- 35 прежних сценариев и 12 дополнительных fix3.
- Сквозные сценарии: 20+3 по умолчанию; 5+5+2; четыре отдельных предмета; ткань Max и трава Single одновременно; сборка из фрагментированных стаков; ограничение завышенного старого значения.
- Во всех сквозных сценариях вызываются настоящие модули очереди, сборки и размещения, проверяется размер в продажном слоте и аргументы StartAuction. Сумки, курсор и сервер моделируются.
- Дополнительно: старые сохранения, зарядовые предметы, ввод и сохранение поля, кнопки Plan/Log/Refresh, переключение Classic/Modern.
- fix5: встроенная база цен вендоров (13797 записей) загружается через TOC; цена для предмета без наблюдений берётся из базы; своя цена из сканов торговца важнее базы; зарядовые предметы делятся на число зарядов; ShaguTweaks важнее встроенной базы; счётчик в настройках включает размер базы; фильтры vendor-profit работают от базы без ShaguTweaks.
- Проверена координатная модель панели Modern/Classic: нет пересечений 16 независимых элементов управления; просмотрены диагностические изображения. Это НЕ игровой рендер и не проверка метрик реального шрифта/текстур WoW.

## Не проверено

Клиент WoW 1.12.1 и нативный Lua 5.0, реальные серверные задержки, все сторонние аддоны, реальная отрисовка в игре. Тестовый загрузчик адаптирует старые конструкции только в памяти; поставочные файлы не преобразованы под Lua 5.3.

## Быстрый тест в игре

1. Резервная копия, полная замена папки, вход без других заменителей аукциона.
2. Дешёвый предмет, запас 12, Custom → 5 → Save. Строка Saved сообщает 5.
3. Post All: в Plan два лота по 5 и один по 2. До подтверждения новых аукционов нет.
4. Проверьте Single, Max и независимые правила двух предметов.
5. Plan/Log/Refresh/Close/Esc без чата.
6. Classic: On, проверка разрешения и масштаба; сохранение после reload.
7. Stop/закрытие окна во время очереди: новых действий нет, уже отправленное действие не откатывается.
8. Навести курсор на предмет, который ни разу не показывали торговцу: строка Vendor в тултипе показывает цену из встроенной базы; в настройках счётчик цен сообщает «+13797 built-in».

## Воспроизведение

Linux, Python 3, динамическая библиотека Lua 5.3: python3 tests/run_checks.py. Результаты: tests/results.txt. Файлы tests не включены в TOC и не выполняются игрой.
