# EasyAH 1.12.1-fix5 — встроенная база цен продажи вендору

## Что просил пользователь
«Сделай, чтобы цена предметов на продажу вендору отображалась для всех предметов, даже для тех, что еще не показывал вендору, то есть для новых.»

## Проблема
Клиент WoW 1.12.1 никогда не сообщает аддонам цену продажи предмета вендору через API. EasyAH знал цену только для предметов, которые игрок уже показывал торговцу (сумки сканируются при открытии окна торговца) или клал в слот продажи аукциона. Для всех остальных предметов тултип показывал «?» или ничего.

## Решение
В аддон встроена статическая база цен ваниллы (1.12.1) на 13797 предметов — `data/vendor_prices.lua` (заполняет глобальную `EasyAH_VendorPriceDB`, формат `[itemid]=цена_в_меди`). Данные взяты из проверенной базы сообщества (ShaguValue, цены ядра ваниллы).

Приоритет цен не изменился и остаётся корректным:
1. Своя наблюдённая цена (скан торговца / слот продажи) — важно для серверов с нестандартными ценами.
2. База ShaguTweaks, если этот аддон установлен.
3. Встроенная база EasyAH.

Предметы с зарядами (масла, гаджеты) корректно делятся на число зарядов — и для встроенной базы тоже. Цена 0 (непродаваемые/квестовые предметы) в базу не включена, чтобы тултип не показывал «0 меди».

## Изменённые файлы
- `data/vendor_prices.lua` — новый файл, встроенная база цен (13797 записей).
- `EasyAH.toc` — подключён файл базы, версия 1.12.1-fix5.
- `core/cache.lua` — комментарий обновлён; `vendor_price_count()` дополнительно возвращает размер встроенной базы.
- `tabs/settings/core.lua` — счётчик в настройках показывает «(+13797 built-in)»; пояснение упоминает встроенную базу.
- `tests/regression.lua` — старый тест адаптирован: раньше при отсутствии ShaguTweaks цена была nil, теперь подставляется встроенная база (тест временно отключает её для проверки nil-ветки).
- `tests/fix5.lua` — 6 новых тестов: база загружена и даёт цену неизвестному предмету; своя цена важнее базы; деление на заряды; ShaguTweaks важнее базы; счётчик включает базу; фильтры vendor-profit работают от базы.
- `tests/run_checks.py` — подключён fix5.lua.

## Как проверить в игре
1. Навести курсор на любой предмет, который вы никогда не носили торговцу (например, только что выбитую ткань/траву) — в тултипе строка «Vendor» показывает цену сразу.
2. Открыть настройки EasyAH — счётчик «Prices known» показывает «+13797 built-in».
3. Продать предмет торговцу один раз — далее используется ваша наблюдённая цена (приоритет выше базы).
